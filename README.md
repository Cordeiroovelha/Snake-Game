# Snake
A repository dedicated to showcase some test with the `Raylib` library, in this case a interpretation of the game *Snake(1997)* for the *Nokia 6110*

## How To Use

if you want just to test the game there is the `.exe` file in the project but, if you wish to change something in the project:

* Install the compiler [MinGW GCC](https://www.mingw-w64.org/) and the library [RayLib](https://www.raylib.com/)
* clone the project
* Open in an text editor I used [VSCode](https://code.visualstudio.com/)
* Download the **C++ Extension pack**
* Compile the project with the `F5` key or with the following command

```bash
C:\raylib\w64devkit\bin\mingw32-make.exe RAYLIB_PATH=C:/raylib/raylib PROJECT_NAME=main OBJS=main.cpp BUILD_MODE=DEBUG
```
